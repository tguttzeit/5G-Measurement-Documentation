# 5G-Messeinheit (5GMU)

Dokumentation der mobilen 5G-Messeinheit der Technischen Hochschule Augsburg:
Anleitungen für den Einsatz im Feld, Hinweise zur Wartung, Fehlerbilder aus dem
Betrieb sowie die Architektur- und Entwicklerdokumentation der Messsoftware.

Documentation for the mobile 5G measurement unit built at Technische Hochschule
Augsburg: field guides, maintenance notes, known failure modes, and the
architecture and developer documentation of the measurement software.
