# Documentation (English)

These pages are for everyone who operates or looks after the measurement unit in
the field, and for everyone who works with the backend.

## Measurement unit

- [Usage](measurement-unit/usage/index.md) – bringing the unit into service, running a measurement campaign, remote commands, adjusting the configuration
- [Maintenance](measurement-unit/maintenance/index.md) – power supply, software updates, recurring checks
- [Troubleshooting](measurement-unit/troubleshooting/index.md) – failure modes seen in operation and how to read them
- [Development](measurement-unit/dev/index.md) – architecture, configuration reference, hardware integration, setting up a unit, local testing and the [Code](../reference/measurement_software/) reference of the measurement software (generated from the docstrings)

## Backend

- [Backend](backend/index.md) – web interface: roles and login, unit status, measurement runs and campaigns, map, settings
- [Development](backend/dev/index.md) – configuration, device registration, deployment, flent server, local testing and the API reference
